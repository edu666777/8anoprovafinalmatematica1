# Revisão de Matemática – 8º Ano (Mentoria Educacional Promover)

Site de estudo de **PFC, Probabilidade e Estatística**: teoria ilustrada, calculadoras interativas, 15 questões com resolução comentada e **relatório de erros enviado pelo WhatsApp** para (85) 99262-1003.

## Publicar no GitHub Pages
1. Envie os arquivos `index.html`, `style.css`, `dados.js`, `app.js` para a raiz do repositório.
2. **Settings → Pages** → *Deploy from a branch* → `main` → `/ (root)` → **Save**.
3. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Editar
- Questões e teoria: `dados.js` (`c` = alternativa correta, 0=A … 3=D).
- Número do WhatsApp: primeira linha de `app.js` (`WHATSAPP`).
